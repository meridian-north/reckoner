# Reporting a security or privacy problem

Contact meridian.north@pm.me with a minimal description. Do not publish private records, credentials, or exploit details in a public issue.

The prototype treats user text as text, uses sandboxed document frames, and does not accept model credentials. JSON digests establish file integrity relationships, not authenticated identity or factual correctness. Browser drafts and document references are local to the device until explicitly exported or shared.

The form is a prototype. A shared hosted intake service, authenticated review, and direct external submission are outside this release. Browser-local catalogue/history coordination is not such a service. Preparing or hashing a record does not establish content safety or sharing permission.
